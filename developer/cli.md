# The user CLI has been removed

The metadata-authoring CLI was removed in v0.5.0.0 and its `pnpm emu` commands are no longer available.

Create and customize Apps, Models, and Artifacts in [Web Designer](../user/web-designer.md). For AI-assisted automation inside an existing App, use the scoped [AI REST proposal API](ai-rest-api.md); every ChangeSet still requires human review and approval.

Export App or Model packages when metadata needs version control, review, or promotion between environments.
